## 과제 수행 
4회차에서 개발한 **스킬을 스킬+에이젼트 구조로 분업화**   

### 스킬 Only -> 스킬 + 에이젼트 구조로 변경 
아래 프롬프트를 적절히 수정하여 수행

아래 예에서 'consult'는 본인 스킬명으로 반드시 수정    
```
[목표]
{SKILL-NAME}: consult
스킬 {SKILL-NAME}를 서브 에이젼트를 만들어 분업 구조로 변경
[역할]
당신은 스킬과 에이젼트를 이용한 업무 자동화 전문가임
[입력]
- 스킬 파일: .claude/skills/{SKILL-NAME}/SKILL.md
[처리]
- 스킬 파일 분석
   - 서브 에이젼트 후보 식별과 호출 방법(순차/병렬), 모델, 툴 결정
   - 선택 가능한 모델: sonnet, opus, fable
   - 병렬 호출 전환 가능한 지 검토
   - AGENTS.md의 팀원과 매칭. 기존에 없는 팀원은 추가 
- 서브 에이젼트 생성
- 스킬 파일 수정
- 완료 보고 
[출력]
.claude/agents/{agent-name}.md
[제약조건]
- MUST: 
  - 작업 중 추가 정보나 의사결정이 필요하면 사용자에게 요청
  - 프롬프트는 프롬프트 작성 가이드를 준용
- MUST NOT
   - 메인 에이젼트는 사용자 인터랙션 작업 외 직접 작업 수행 금지
- 완료조건: 
  - 에이젼트 파일 생성
  - AGENTS.md의 팀원과 매칭
```

### 프로젝트 업로드   
- 원격 Git Repository 생성 후 푸시 
  프롬프트 창에서 요청   
  ```
  push
  ```

  ※ 최초 푸시면 원격 레포지토리 만들고 푸시   
  예) ORG명과 레포지토리명은 본인걸로 변경  
  ```
  ORG 'unicorn-bootcamp'에 private repository 'security-check'를 생성하고 푸시  
  ```

- Agent 이름과 본인이 커스터마이징한 사항 요약  
  Claude Code가 생성한 Agent를 어떻게 커스터마이징했는지 기술하세요.

  ```

  - As-Is: 마크다운으로 레포트 생성
  ```   
